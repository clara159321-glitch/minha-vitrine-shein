Adicionar roupas ✨

Seu painel simples para cadastrar vestidos, conjuntos e outros achadinhos.

1. Preencha a roupa

Escolha uma foto do celular (até 2 MB). Use imagens que você tem autorização para publicar. Sem link, o botão de compra fica desativado. Use o link de afiliada, não apenas o ID do produto.
Mais opções

2. Publique na vitrine

Depois de salvar suas roupas, faça estes dois passos:

  1. Baixe o arquivo products.json pelo botão ①.
  2. Toque no botão ②, selecione choose your files e escolha o arquivo baixado.
  3. Confirme Commit changes na branch main. Se o GitHub perguntar sobre substituir o arquivo, confirme.
  4. Aguarde alguns minutos e abra sua vitrine para conferir.

Importante: Salvar roupa guarda um rascunho só neste navegador. A vitrine pública muda apenas após enviar o arquivo e confirmar no GitHub.
