Como publicar as alterações
  1. Toque em “Baixar products.json para publicar”.
  2. Abra seu repositório no GitHub, entre na sua conta e selecione a aba Code e a branch main.
  3. Toque em Add file → Upload files. No celular, a opção pode ficar no menu “+” ou “⋯” da lista de arquivos.
  4. Escolha o products.json baixado, mantendo esse nome, e toque em Commit changes. Confirme a gravação na branch main.
  5. Com GitHub Pages ativado, aguarde a publicação e atualize a vitrine.

Somente quem tem acesso de escrita ao seu repositório pode publicar. Nenhuma senha ou token é solicitado aqui.
